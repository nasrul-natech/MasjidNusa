# Audio Adzan

Letakkan file audio adzan di folder ini:

- `adzan-makkah.mp3` - Suara adzan dari Makkah
- `adzan-madinah.mp3` - Suara adzan dari Madinah

File audio bisa diunduh dari sumber yang halal dan bebas hak cipta.
Opsi "Sederhana" menggunakan tone yang di-generate via Web Audio API (tidak perlu file MP3).
